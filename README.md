# Nağme

Reklamsız, arka planda çalan müzik uygulaması (Android). Erkam Yazılım — Geliştirici: Sadullah Akça.

- YouTube'dan sadece ses çalar (NewPipe Extractor + Media3)
- Ekran kapalıyken çalar, bildirim ve kilit ekranı kontrolleri
- Yumuşak geçiş, kulaklık takınca devam, uyku zamanlayıcı
- Dinlediklerine göre öneriler, benzer şarkılarla otomatik devam
- Cihaza hızlı kaydetme ve internetsiz dinleme
- Dönen plak gibi yüzen simge
